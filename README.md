# Nurullah • 100 Günlük TYT + AYT

Nurullah için sıfırdan hazırlanacak 100 günlük sayısal YKS çalışma takip uygulaması.

## İlkeler
- Yusuf'un 67 günlük programından hiçbir konu dağılımı alınmaz.
- Programda standart TYT/AYT ana başlıkları yer alır; alt kazanımlar ayrı referans envanterinde izlenir.
- 100 gün, yaklaşık 7 saat/gün öğrenme ve pekiştirme hedeflenir. Bu süre tek başına tam sınav yetkinliğini garanti etmez.
- Mobil uyumlu, çevrimdışı çalışabilen, ilerleme yedeklenebilen PWA tasarlanır.

## Kaynak temeli
MEB'in 2026 YKS kazanım/açıklamaları, standart YKS konu tasnifi ve kullanıcının TYT/AYT ayrıntılı konu envanteri. 2027 kapsamı resmî duyurularla ayrıca doğrulanmalıdır.
